# Yellora Industries website — Phase 1

Responsive static website prototype built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local development server, run:
```bash
python -m http.server 8000
```
Then open http://localhost:8000.

## Included
- Yellora Industries logo and product photographs extracted from the supplied company document.
- Responsive home page, product overview, about, custom solutions and contact sections.
- WhatsApp contact links for both supplied phone numbers.
- Product enquiry links with a choice of WhatsApp number.

## Before public launch
- Confirm product specifications, particularly the E-Trolley load capacity (the supplied document shows both 150 kg and 300 kg in different places).
- Confirm whether service/repair, battery replacement, spare parts and on-site service are offered.
- Confirm final product names, approved descriptions, pricing policy, warranty and regulatory/compliance claims.
- Replace or supplement any product image that is not a photograph of the exact model being offered.
- Test phone numbers and WhatsApp links with the business owner.

No prices, warranty claims, certifications or unprovided performance figures have been invented.
